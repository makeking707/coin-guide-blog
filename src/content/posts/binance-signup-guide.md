바이낸스는 거래량 기준으로 가장 큰 해외 거래소예요. 이 글에서는 **가입 → 본인 인증(KYC) → 보안 설정**까지 처음 쓰는 분이 막히지 않도록 순서대로 정리했어요.

> 이용 전에 확인하세요: 해외 거래소는 국내 「특정금융정보법」에 따른 신고 사업자가 아니에요. 문제가 생겨도 국내 이용자 보호 제도가 적용되지 않을 수 있어요.

## 1. 가입 전에 준비할 것

- 자주 쓰는 **이메일** 또는 **휴대폰 번호**
- **신분증** (주민등록증, 운전면허증, 여권 중 하나)
- 2단계 인증용 **인증 앱** (Google Authenticator 등)
- 피싱 사이트를 피하려면 **공식 주소를 직접 입력하거나 공식 앱스토어 앱**을 쓰세요. 검색 광고 링크는 가짜일 수 있어요.

## 2. 회원가입 순서

1. 바이낸스 공식 사이트나 앱에서 **회원가입**을 눌러요.
2. 이메일 또는 휴대폰 번호를 입력해요.
3. **추천 코드(Referral ID) 입력란**을 확인해요. 접혀 있는 경우가 많으니 펼쳐서 입력 여부를 꼭 확인하세요. 가입이 끝나면 대부분 바꿀 수 없어요.
4. 이메일·문자로 온 인증 번호를 입력해요.
5. 비밀번호를 설정해요. 다른 사이트에서 쓰는 비밀번호는 피하세요.

## 3. 본인 인증(KYC) 하기

KYC를 하지 않으면 입금·출금·거래에 제한이 있어요.

1. 계정 메뉴에서 **본인 인증(Identification)**을 눌러요.
2. 거주 국가를 **대한민국**으로 선택해요.
3. 이름·생년월일을 **신분증과 똑같이** 입력해요. 영문 이름은 여권 표기와 맞추는 게 좋아요.
4. 신분증 앞면(필요하면 뒷면)을 촬영해요.
5. 얼굴 인증을 진행해요.

심사는 보통 몇 분에서 하루 정도 걸려요. 거절됐다면 [바이낸스 KYC 거절 사유 정리](../binance-kyc-rejected/)를 참고하세요.

## 4. 보안 설정 (가입 직후 바로)

| 설정 | 이유 |
|---|---|
| 2단계 인증(인증 앱) | 비밀번호가 유출돼도 로그인·출금을 막아요 |
| 패스키 또는 보안키 | 피싱에 강한 로그인 방식이에요 |
| 안티피싱 코드 | 바이낸스가 보내는 진짜 메일에만 내가 정한 코드가 표시돼요 |
| 출금 주소 화이트리스트 | 등록한 주소로만 출금되게 막아요 |

출금 주소 화이트리스트는 [출금 주소 등록 방법](../withdrawal-address-low-fee-coins/) 글에서 자세히 다뤄요.
