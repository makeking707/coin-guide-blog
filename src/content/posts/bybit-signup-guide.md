바이비트는 선물 거래로 잘 알려진 해외 거래소예요. **가입 → 본인 인증 → 인증 실패 시 해결**까지 정리했어요.

> 이용 전에 확인하세요: 해외 거래소는 국내 신고 사업자가 아니며, 국내 이용자 보호 제도가 적용되지 않을 수 있어요.

## 1. 회원가입

1. 바이비트 공식 사이트나 공식 앱에서 **가입하기**를 눌러요.
2. 이메일 또는 휴대폰 번호를 입력하고 비밀번호를 정해요.
3. **추천 코드 입력란**을 확인해요. 가입이 끝나면 넣기 어려워요.
4. 인증 번호를 입력하면 가입이 끝나요.

## 2. 본인 인증(KYC)

1. 계정 메뉴의 **본인 인증**으로 들어가요.
2. 국적과 거주 국가를 선택해요.
3. 신분증 종류를 고르고 촬영해요.
4. 얼굴 인증을 진행해요.

## 3. 인증이 실패하는 흔한 원인

| 원인 | 해결 |
|---|---|
| 사진이 흐리거나 빛이 반사됨 | 밝은 곳에서 그림자·반사 없이 네 모서리가 모두 나오게 촬영해요 |
| 이름 표기 불일치 | 신분증(여권) 영문 표기와 띄어쓰기까지 똑같이 입력해요 |
| 유효기간이 지난 신분증 | 유효한 신분증으로 다시 제출해요 |
| 국적·거주 국가 선택 오류 | 실제 국적과 거주지를 정확히 선택해요 |
| 이미 다른 계정에서 같은 신분증으로 인증함 | 1인 1계정이 원칙이라 기존 계정을 써야 해요 |
| 사진 대신 화면을 다시 찍음 | 원본 신분증을 직접 촬영해요 |

## 4. 가입 후 할 일

- **2단계 인증**과 **출금 주소 화이트리스트**를 설정하세요.
- 수수료 구조는 [바이비트 수수료 구조와 VIP 등급](../bybit-fees-guide/)에서 확인하세요.
- 바이낸스와 고민 중이라면 [바이낸스 vs 바이비트 수수료 비교](../binance-vs-bybit-fees/)를 참고하세요.
