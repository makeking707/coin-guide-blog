거래소 사이에서 코인을 자주 옮긴다면 **출금 주소 관리**와 **전송 코인 선택**이 중요해요. 보안도 지키고 수수료도 아낄 수 있어요.

## 1. 출금 주소 화이트리스트란?

미리 등록한 주소로만 출금되게 하는 기능이에요. 계정이 털려도 공격자가 자기 주소로 출금하기 어려워요.

### 바이낸스

1. **계정 → 보안**으로 들어가요.
2. **출금 화이트리스트(Address Management)**를 찾아요.
3. 코인, 네트워크, 주소, 메모(태그)를 입력하고 이름을 붙여 저장해요.
4. 화이트리스트 기능을 **켜기**로 바꿔요.

### 바이비트

1. **계정 → 보안 → 출금 주소 관리**로 들어가요.
2. 주소를 추가하고, **화이트리스트 주소로만 출금** 옵션을 켜요.

메뉴 이름은 앱 업데이트에 따라 조금씩 달라질 수 있어요.

## 2. 전송 코인 고르는 기준

| 기준 | 확인 방법 |
|---|---|
| 출금 수수료 | 보내는 거래소 출금 화면에 표시돼요 |
| 도착 속도 | 블록 생성 속도와 필요한 컨펌 수에 따라 달라요 |
| 네트워크 지원 | 보내는 쪽과 받는 쪽이 **같은 네트워크**를 지원해야 해요 |
| 태그(메모) 필요 여부 | 일부 코인은 주소 외에 태그가 필수예요 |
| 가격 변동 | 전송 중에도 가격이 움직이니, 도착 후 바로 필요한 코인으로 바꾸는 경우가 많아요 |

일반적으로 리플(XRP), 트론(TRX), 솔라나(SOL) 계열처럼 **수수료가 낮고 빠른 네트워크**가 자주 쓰여요. 다만 거래소별 지원 여부와 수수료는 계속 바뀌니 **출금 화면에서 직접 비교**하세요. 이 글은 특정 코인의 매수를 권하는 글이 아니에요.

## 3. 실수를 막는 체크리스트

- [ ] 받는 쪽에서 복사한 주소인가?
- [ ] 네트워크가 양쪽 모두 같은가?
- [ ] 태그(메모)가 필요한 코인이면 입력했는가?
- [ ] 처음 보내는 주소면 **소액으로 먼저 테스트**했는가?
