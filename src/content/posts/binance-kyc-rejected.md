KYC가 거절되면 입출금이 막혀서 답답하죠. 바이낸스 KYC가 거절되는 **대표 원인과 해결 방법**을 정리했어요.

## 1. 먼저 거절 사유 확인

**계정 → 본인 인증** 화면이나 이메일에 거절 사유가 적혀 있어요. 사유에 맞는 부분만 고쳐서 다시 제출하는 게 가장 빨라요.

## 2. 대표 거절 사유와 해결

| 거절 사유 | 해결 방법 |
|---|---|
| 신분증 사진이 흐림·잘림 | 밝은 곳에서 초점을 맞추고 네 모서리가 모두 보이게 찍어요 |
| 빛 반사·그림자 | 조명 바로 아래를 피하고, 신분증을 살짝 기울여 반사를 없애요 |
| 이름·생년월일 불일치 | 입력 정보를 신분증과 **글자 하나까지** 똑같이 맞춰요 |
| 영문 이름 표기 차이 | 여권 영문 표기를 기준으로 성·이름 순서와 띄어쓰기를 맞춰요 |
| 유효기간 만료 | 유효한 신분증으로 교체해요 |
| 얼굴 인증 실패 | 모자·안경·마스크를 벗고, 밝은 곳에서 화면 안내대로 천천히 움직여요 |
| 국가 선택 오류 | 국적과 거주 국가를 실제 정보와 맞춰요 |
| 이미 다른 계정에서 인증됨 | 1인 1계정 원칙이라 기존 계정을 찾아 써야 해요 |

## 3. 재신청 전 체크리스트

- [ ] 거절 사유를 확인했나요?
- [ ] 신분증 원본을 직접 촬영했나요? (스캔본·화면 재촬영 금지)
- [ ] 입력한 이름이 신분증과 완전히 같나요?
- [ ] 네트워크가 안정적인 곳에서 진행하나요? (얼굴 인증 중 끊기면 실패해요)
- [ ] 앱을 최신 버전으로 업데이트했나요?

## 4. 계속 거절될 때

- 같은 사진으로 반복 제출하면 계속 실패해요.
- 공식 고객센터 채팅으로 **거절 사유 화면 캡처**와 함께 문의하세요.
- 고객센터를 사칭하는 메신저·전화에 주의하세요. 바이낸스 직원은 비밀번호나 인증 코드를 묻지 않아요.
