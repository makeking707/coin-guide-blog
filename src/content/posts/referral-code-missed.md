가입할 때 추천 코드 입력란을 놓치는 경우가 정말 많아요. 지금 할 수 있는 방법을 정리했어요.

## 1. 먼저 알아둘 것

- 추천 코드는 **가입할 때만** 입력하는 구조가 대부분이에요.
- 가입 후 추가·변경이 되는지는 **거래소 정책**에 따라 달라요. 인터넷에 도는 "무조건 된다"는 방법은 공식 정책과 다를 수 있어요.

## 2. 지금 해볼 수 있는 방법

### ① 앱에서 입력 메뉴가 있는지 확인

가입 직후 일정 기간 동안 추천 코드 입력 메뉴가 보이는 경우가 있어요. **계정 → 추천(Referral)** 또는 **이벤트 코드** 메뉴를 확인해 보세요.

### ② 고객센터에 문의

메뉴가 없다면 공식 고객센터 채팅으로 문의해요.

> 문의 예시: "가입 시 추천 코드 입력을 누락했습니다. 가입일은 ○월 ○일이며, 적용하려던 코드는 ○○○○입니다. 사후 적용이 가능한지 확인 부탁드립니다."

가입한 지 오래됐거나 이미 거래를 많이 했다면 거절될 가능성이 높아요.

### ③ 지금 계정에서 수수료를 줄이는 방법 쓰기

추천 코드 혜택이 없어도 수수료를 줄일 방법이 있어요.

- 바이낸스: [BNB로 수수료 할인받는 방법](../binance-bnb-fee-discount/)
- 공통: [메이커 주문으로 수수료 줄이기](../maker-taker-fee-explained/)

## 3. 하지 말아야 할 것

| 방법 | 문제 |
|---|---|
| 다른 사람 명의로 새 계정 만들기 | 약관 위반이며, 명의 대여는 법적 문제가 될 수 있어요 |
| 탈퇴 후 재가입 | 재인증 제한, 자산·내역 손실 위험이 있어요 |
| 비공식 "코드 변경 대행" 업체 이용 | 계정 정보를 넘겨주면 해킹 피해로 이어질 수 있어요 |

## 4. 다음에 가입할 때

- 가입 화면에서 **추천 코드 입력란을 펼쳐서** 직접 확인하세요.
- 간편 가입(구글·애플)보다 **이메일 가입**이 입력란을 확인하기 쉬워요.
- 가입 직후 추천 메뉴에서 적용 여부를 확인하세요.
